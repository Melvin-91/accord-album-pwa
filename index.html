IMPOSTAZIONI PRIVATE

GitHub e Spotify

Crea un token limitato al solo repository privato accord-music-data, con permesso Contents in lettura/scrittura. Il token viene memorizzato in questo profilo browser; chiunque possa usare il profilo potrebbe accedervi. Non inserirlo in URL, file o repository. Il token non viene inviato a servizi diversi da api.github.com.

SPOTIFY

Registra questo Redirect URI nelle impostazioni della tua app Spotify. La connessione usa OAuth Authorization Code con PKCE: non inserire un client secret. I token Spotify restano solo nella sessione del browser e non vengono sincronizzati.

IMPORTAZIONE SPOTIFY

Album da playlist

Spotify richiede l’autorizzazione per leggere le playlist private e collaborative. Verranno salvati solo i record album previsti da Accord, non brani o dati della playlist. L’importazione non avvia la sincronizzazione GitHub.
